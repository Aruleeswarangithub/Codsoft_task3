# 🧮 Simple Calculator - Web App

Hey, it's **your friendly dev!** 🚀 Welcome to **Simple Calculator**, a web-based tool to perform **quick and easy calculations**. Let's calculate efficiently! 🎉

---
## ✨ Features

✔ **Basic Arithmetic Operations** – Perform Addition (+), Subtraction (-), Multiplication (×), Division (÷), and Percentage (%).  
✔ **Clear & Backspace** – Easily correct mistakes with the **C** and **←** buttons.  
✔ **User-Friendly Interface** – Simple and clean design with **responsive buttons**.  
✔ **Instant Results** – Get accurate calculations with a single click!  
✔ **Minimal & Lightweight** – Works on any modern web browser without extra dependencies.  

---
## 🛠️ Technologies Used

🔹 **HTML** – Provides the structure for the calculator.  
🔹 **CSS** – Styles the calculator with a visually appealing design.  
🔹 **JavaScript** – Handles the logic for calculations and user interactions.

## 📝 File Structure

📂 `index.html` – Contains the calculator layout.  
🎨 `styles.css` – Adds styling and responsiveness.  
📜 `index_.js` – Handles button clicks and calculations.  

---
## 🔍 JavaScript Functionality

📌 `Clear()` – Clears the input field.  
📌 `Back()` – Removes the last character from the input field.  
📌 `Solve(value)` – Appends a clicked button value to the input field.  
📌 `Result()` – Evaluates the mathematical expression entered and displays the result.
